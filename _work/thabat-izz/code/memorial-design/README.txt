سيرة الشهيد النقيب رائد أحمد محمد سيف الكحلاني — ملفات التصميم
====================================================================

المجلدات
--------
exports/final/        التصاميم النهائية PNG بدقة عالية (مربع 2160×2160، أفقي 3840×2160)
exports/final-jpg/    نفس التصاميم بصيغة JPG جاهزة للنشر
exports/previews/     معاينات الاتجاهات الستة + لوحة المقارنة 00-concepts-sheet.jpg
exports/00-finals-overview.jpg   لوحة كل النسخ النهائية
html/                 ملفات التصميم القابلة للتعديل (افتحها في المتصفح)
src/content.py        كل نصوص السيرة في مكان واحد — عدّل النص هنا فقط
src/build.py          يولّد ملفات html من content.py (6 اتجاهات × مربع/أفقي × نسختي الصورة)
src/render.js         يصدّر الصور PNG ويفحص خروج النص عن الإطار وتداخله
assets/               الصور المحسّنة (في البؤرة / مفرّغة / الأصل / المكبّرة ×4)، الشعار، الخامات
fonts/                خطوط ثمانية (للاستخدام الخاص بالقناة — لا تُنشر)

أسماء الملفات
-------------
1-editorial = سجلّ الشرف   2-commander = القائد   3-archive = الوثيقة
4-cinematic = الضوء الأخير   5-minimal = الهدوء   6-timeline = خطّ العمر
sq = مربع 1:1   ls = أفقي 16:9   focus = الصورة كاملة وهو في البؤرة   cut = مفرّغة بلا خلفية

إعادة التصدير بعد تعديل النص
----------------------------
cd kahlani && python3 -m http.server 8777 &
cd src && python3 build.py
OUT=final SCALE=2 node render.js ../html/1-*.html ../html/2-*.html ../html/3-*.html
(يحتاج Python 3 و Node مع Playwright)
