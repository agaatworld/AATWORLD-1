# Changelog

## 0.1.0 — first build

* Floating toolbar (vertical/horizontal, three sizes, collapsible launcher, adapts to small screens), tool library with search, pinning, reordering, presets and ready-made layouts.
* One click-through drawing layer per monitor; pen with pressure and smoothing, highlighter, laser pointer, arrow, line, rectangle, ellipse (fill, dash, corner radius), text labels (Arabic-aware), numbered step markers, images (file or paste), whiteboard/blackboard, object and partial erasers.
* Select, move, resize, rotate, duplicate, lock, arrange, contextual inspector; global undo/redo across monitors.
* Workspaces, autosave, daily backups, restore.
* Desktop-safety system: native click-through with style/focus guards, Escape safety key, heartbeat watchdog with automatic rebuild, main-thread guard, tray control.
* English and Arabic interface; dark, light and system themes; reduced motion.
* Windows CI: tests, NSIS installer and a native self-test of click-through on a real Windows session.
